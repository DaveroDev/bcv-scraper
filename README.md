El sistema ha sido diseñado con una arquitectura modular que permitirá expandir sus capacidades en futuras versiones mediante el siguiente mapa de ruta:

- [ ] **Módulo Multimoneda Ampliado:** Incorporar el soporte y procesamiento de otras divisas oficiales indexadas por el BCV (como Yuanes CNY, Rublos RUB y Liras TRY).
- [ ] **Sistema de Personalización Visual (Temas):** Implementar un motor de temas dinámicos dentro de la aplicación para permitir al usuario alternar entre modos oscuros, claros y paletas de colores personalizadas que se reflejen tanto en la App como en los Widgets.
- [ ] **Historial de Variación Diaria:** Desarrollar una base de datos local ligera (Room) para almacenar los cierres de las tasas y mostrar gráficos de rendimiento o fluctuación de la moneda a lo largo de la semana.
